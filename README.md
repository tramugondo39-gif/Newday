# The Nirvana Experience

A responsive React + Vite single-page experience featuring a minimalist music room, the NVNA TASTE 25-track playlist, song search, saved favourites, Spotify search links, mood picker, and a note popup.

## Run locally
1. Install Node.js (18+ recommended).
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL shown by Vite.
4. Run `npm run build` to create the production build in `dist/`.

## Deploy
Import the extracted folder/repository into Vercel. Framework preset: Vite. Build command: `npm run build`. Output directory: `dist`.
